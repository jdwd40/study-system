# Structured extraction

## Objective

Understand and apply structured extraction in a reliable AI automation and systems-integration workflow.

## Content

**Understand**

A business system needs fields, not a paragraph it must guess how to parse. Define a schema with a small set of categories, a short summary, a contact preference and nullable fields for unknown facts. Validate the returned structure independently of the model; a valid JSON object can still contain invented facts. Distinguish unknown from empty and from false. Put the source text alongside the extracted data, and require evidence spans for fields that matter. A confidence number generated by a model is not a calibrated probability. Let explicit review rules decide when a person must inspect the record.

**Worked example**

“My brakes squeal, call after 6” yields category=brakes, contactPreference=phone_after_18, appointmentDate=null. It must not invent a booking date.

**Try it**

Write a seven-field enquiry schema. For three sample messages, fill the fields and mark absent facts null. Define what makes a result invalid.

**Key point**

Constrained shape, validation, evidence, explicit unknowns.
