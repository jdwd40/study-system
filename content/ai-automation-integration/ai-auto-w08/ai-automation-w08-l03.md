# Review and demonstrate the lead assistant

## Objective

Understand and apply review and demonstrate the lead assistant in a reliable AI automation and systems-integration workflow.

## Content

## Understand

A portfolio project needs evidence: a short screen recording or screenshots, architecture in one page, sample test results and a clear statement of what the owner approves. Demonstrate normal operation, ambiguous input and a failure. Show measured time per enquiry and how you counted it; never claim savings not observed. Include a data flow drawing, deployment notes and a “known limitations” section. The reviewer should be able to understand the user benefit before seeing the tools. End with one concrete iteration based on test findings.

## Worked example

The demo shows a new lead, a flagged uncertain lead and a duplicate event that creates no second task.

## Try it

Run the acceptance checklist in the project brief, capture evidence and write a 200-word case study using only observed facts.
