# Storytelling, Description and Voice

Apply the same foundations to fiction and narrative nonfiction. Planned lessons: Concrete Detail and Selective Description (25 min); Character, Desire and Scene (35 min); Point of View, Dialogue and Voice (40 min).

## Learning Objectives

- Choose concrete details that serve mood, meaning or character.
- Build a short scene around desire, an obstacle and a change.
- Maintain a deliberate viewpoint and distinguish character dialogue from authorial voice.
