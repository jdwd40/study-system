# Explanation, Evidence and Argument

Explain accurately and argue fairly, separating claims from support. Planned lessons: Explaining an Idea to a Non-Specialist (30 min); Claims, Evidence and Reasoning (35 min); Counterarguments, Sources and Fair Conclusions (40 min).

## Learning Objectives

- Explain an unfamiliar idea with a useful example and defined terms.
- Distinguish claims, evidence, inference and opinion; connect support to a conclusion.
- Represent a counterargument fairly and attribute quotations, paraphrases and sources.
