# Software Systems Engineering

Move from building applications to engineering complete modern software systems: architecture, constraints, trade-offs, data, failure, security, operations and evolution.

Assumes programming, JavaScript, Python, Node.js, React, APIs, basic databases, Git and web development. Prepares for AI-driven development by treating models, agents, retrieval and evaluation as components in larger systems.
